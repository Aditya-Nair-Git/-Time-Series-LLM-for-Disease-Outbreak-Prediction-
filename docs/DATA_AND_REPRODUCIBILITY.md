# Data and reproducibility

The capstone report refers to the main file as `Final_data.csv` and describes an external dengue dataset for San Juan/Iquitos. Expected core columns are `Disease`, `Cases`, `week_of_outbreak`, `state_ut`, `district`, `Temp`, and `preci`; `LAI`, coordinates and `year` are used if available.

1. Obtain the original dataset from the source used by the capstone team.
2. Put it at `data/raw/Final_data.csv`.
3. Run `python scripts/prepare_data.py --input data/raw/Final_data.csv`.
4. Run `python scripts/train_models.py`.
5. Review `artifacts/metrics.json`.

Preparation parses week numbers, converts temperature values above 100 (assumed Kelvin) to Celsius, drops duplicate rows, and excludes 2020–2022 by default as described in the report appendix. Use `--keep-pandemic-years` to retain those years.

The original CSV and trained model checkpoints were absent from the linked repository snapshot. Metrics generated by this reconstruction are not the original report's results. The training script uses a random split as a quick baseline; credible forecasts need time-forward evaluation and external validation. Demo outputs are synthetic examples, not health guidance.
